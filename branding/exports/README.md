# DailyHub logo exports

The SVG files are the source-of-truth logo masters. JPEGs are flattened previews for tools that do not accept SVG.

| Variant | SVG | JPEG background |
| --- | --- | --- |
| Primary mark | `dailyhub-mark.svg` | Paper |
| Inverse mark | `dailyhub-mark-inverse.svg` | Ink |
| Primary lockup | `dailyhub-lockup.svg` | White |
| Inverse lockup | `dailyhub-lockup-inverse.svg` | Ink |

Use the mark alone where the DailyHub name is already visible, and use the lockup for standalone brand placements. Prefer SVG for production UI and print; use JPEG only where transparency and vector scaling are unavailable.
